关于我们

卓然创客社团是武威第十八中学最具活力的科技创新团体，我们致力于将创意变为现实。

我们的使命

我们相信每个学生都有无限的创造潜能。通过提供先进的工具、专业的指导和开放的环境，我们激发学生的创新思维，培养未来的科技领袖。

提供前沿科技设备与工具

组织创新工作坊与培训

参加各级科技创新竞赛

活动展示

我们定期举办各类创客活动，从3D打印到机器人编程，从电子设计到人工智能应用。

3D打印工作坊

学习3D建模与打印技术，将创意转化为实体作品。从简单的钥匙扣到复杂的机械结构，我们一步步指导。

每周三下午

机器人编程

从基础编程到复杂算法，探索机器人的无限可能。我们使用Arduino和树莓派等平台进行教学。

每周五下午

电子创客日

学习电路设计、焊接技术和嵌入式系统开发。制作自己的智能设备，体验创造的乐趣。

每月第一个周六

项目成果

探索我们社团成员完成的创新项目和竞赛成果

智能农业监控系统

2024年省级一等奖

基于物联网的智能农业监控系统，能够实时监测土壤湿度、光照强度、温度等参数，并通过手机App远程控制灌溉和通风设备。

物联网 Arduino 传感器 App开发

自主导航机器人

2023年市级特等奖

基于计算机视觉和SLAM技术的自主导航机器人，能够在复杂环境中自主建图、定位和路径规划，具备避障和目标识别功能。

机器人 计算机视觉 SLAM Python

网页设计信息

网页设计说明

本页面专为武威第十八中学卓然创客社团设计，采用现代化科技风格，结合深色主题与高亮色对比，创造视觉冲击力强的用户体验。页面完全响应式，支持深色/浅色模式切换，并保留了原有的完整登录功能。

配色方案：深色背景 + 高亮色 (#03fc90, #fc03f8)
响应式设计：适配所有屏幕尺寸
深色/浅色模式：一键切换
技术栈：HTML5, Tailwind CSS, Font Awesome
