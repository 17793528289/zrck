# 武威第十八中学卓然创客社团网站开发方案

## 技术栈选择
- **前端**：HTML5 + Tailwind CSS v4 + 原生JavaScript
- **后端**：Supabase (用户认证、数据存储、API、实时数据库)
- **图标**：Font Awesome
- **部署**：静态网站托管（如GitHub Pages、Vercel等）

## 核心功能实现

### 1. 项目初始化与配置
- 创建基础项目结构
- 配置Tailwind CSS（使用CDN方式）
- 集成Font Awesome图标库
- 配置Supabase客户端

### 2. 首页开发
- Hero区域：大型视觉元素，突出社团名称和核心价值
- 社团简介：简明扼要介绍社团历史和目标
- 核心功能展示：软件学习、硬件学习、学业竞赛等模块
- 最新活动：展示近期社团活动
- 社团风采：精选图片展示

### 3. 社团简介页
- 社团历史：发展历程和重要里程碑
- 社团宗旨：核心价值观和目标
- 组织结构：社团管理架构
- 指导教师：教师团队介绍

### 4. 社团活动页
- 活动列表：分类展示所有活动
- 活动详情：详细的活动信息和报名功能
- 活动回顾：过往活动的图片和总结

### 5. 社团展示页
- 社团活动展示：详细的活动列表和图片
- 成果展示：社团项目和竞赛成果
- 成员介绍：核心成员展示
- 设备资源：社团硬件设备和软件资源

### 6. 登录/注册系统
- Supabase认证集成：实现账号/密码登录
- 注册功能：新成员注册入口
- 忘记密码：密码重置功能
- 登录状态管理：前端状态维护

### 7. 访客中心
- 社团信息浏览：公开的社团信息
- 活动查看：浏览社团活动
- 留言板：访客留言功能
- 加入我们：申请加入社团的入口

### 8. 社员中心
- 个人信息管理：社员个人资料编辑
- 活动参与：已参与活动记录
- 项目管理：个人参与的项目
- 通知中心：社团内部通知
- 签到：社团活动签到
- 聊天系统入口：进入社员聊天系统

### 9. 教师中心
- 活动管理：发布和管理活动
- 成员管理：查看和管理社员信息
- 项目指导：指导和管理社团项目
- 资源管理：管理社团资源
- 签到管理：发布签到，管理签到数据

### 10. 后台管理系统
- 用户管理：所有用户的管理和权限控制
- 内容管理：网站内容的编辑和发布
- 活动管理：活动的创建、编辑和删除
- 数据统计：社团运营数据统计

### 11. 社员聊天系统（新增）
- **实时聊天**：利用Supabase实时数据库实现
- **聊天功能**：
  - 社团群聊：所有社员可参与的公共聊天
  - 项目组聊天：基于项目的群聊
  - 私信功能：社员之间的一对一聊天
- **消息管理**：
  - 消息历史记录
  - 未读消息提示
  - 消息发送状态
- **用户体验**：
  - 响应式聊天界面
  - 表情符号支持
  - 消息通知
- **权限控制**：仅限已登录的社员使用

## 设计与交互实现

### 1. 视觉设计
- **配色方案**：深色背景 (#121212)，强调色 #03fc90 和 #fc03f8
- **字体**：中文使用无衬线字体，英文使用 Inter 或 Roboto
- **布局**：响应式设计，适配手机、平板和桌面设备
- **风格**：科技感与教育属性结合，简洁现代

### 2. 交互效果
- **主题切换**：深色/浅色模式切换功能，保存用户偏好
- **动画效果**：按钮悬停、卡片阴影、页面过渡等
- **响应式导航**：移动端汉堡菜单，桌面端水平导航
- **表单验证**：实时表单验证和错误提示
- **聊天界面**：消息发送动画、滚动效果、输入状态提示

### 3. 性能优化
- **图片优化**：使用适当的图片格式和大小，实现懒加载
- **代码优化**：减少不必要的JavaScript，优化DOM操作
- **资源加载**：合理使用缓存，减少重复请求
- **Supabase优化**：
  - 使用适当的查询方法，减少数据库负载
  - 优化实时订阅，避免不必要的更新
  - 消息批量处理，减少网络请求

## Supabase数据库设计

### 1. 用户表 (profiles)
- id (主键)
- username (用户名)
- full_name (姓名)
- email (邮箱)
- avatar_url (头像)
- role (角色: member, teacher, admin)
- joined_at (加入时间)
- bio (个人简介)

### 2. 活动表 (activities)
- id (主键)
- title (标题)
- description (描述)
- start_date (开始时间)
- end_date (结束时间)
- location (地点)
- organizer (组织者)
- status (状态: upcoming, ongoing, past)
- category (分类)
- images (图片URL数组)
- created_at (创建时间)

### 3. 活动报名表 (activity_registrations)
- id (主键)
- activity_id (活动ID)
- user_id (用户ID)
- status (状态: registered, attended, cancelled)
- registered_at (报名时间)

### 4. 项目表 (projects)
- id (主键)
- title (标题)
- description (描述)
- members (成员ID数组)
- mentor (指导教师ID)
- status (状态: planning, in_progress, completed)
- images (图片URL数组)
- created_at (创建时间)

### 5. 签到表 (checkins)
- id (主键)
- activity_id (活动ID)
- user_id (用户ID)
- checkin_time (签到时间)
- location (签到地点，可选)

### 6. 留言表 (messages)
- id (主键)
- name (姓名)
- email (邮箱)
- content (内容)
- is_approved (是否审核通过)
- created_at (创建时间)

### 7. 通知表 (notifications)
- id (主键)
- title (标题)
- content (内容)
- recipient_ids (接收者ID数组)
- is_read (是否已读)
- created_at (创建时间)

### 8. 聊天表 (chats)（新增）
- id (主键)
- type (类型: group, private)
- name (群聊名称，私聊可为空)
- participants (参与者ID数组)
- last_message (最后一条消息内容)
- last_message_time (最后一条消息时间)
- created_at (创建时间)

### 9. 聊天消息表 (chat_messages)（新增）
- id (主键)
- chat_id (聊天ID)
- sender_id (发送者ID)
- content (消息内容)
- type (类型: text, image, file)
- status (状态: sent, delivered, read)
- created_at (创建时间)

### 10. 聊天成员表 (chat_members)（新增）
- id (主键)
- chat_id (聊天ID)
- user_id (用户ID)
- joined_at (加入时间)
- last_read_at (最后阅读时间)

## 优势与挑战

### 优势
- **低学习成本**：无需配置复杂的构建工具，上手快
- **部署简单**：静态网站托管，成本低
- **性能优异**：减少了框架开销，加载速度快
- **维护方便**：代码结构清晰，易于理解和修改
- **实时功能**：利用Supabase实时数据库实现聊天等实时功能

### 挑战
- **代码复用性**：原生JavaScript的模块化需要手动管理
- **状态管理**：复杂状态需要自行实现
- **路由管理**：页面导航需要手动处理
- **Supabase集成**：需要手动处理API调用和错误处理
- **聊天系统复杂性**：实时聊天功能的实现需要处理多种场景

### 应对策略
- 使用合理的文件组织和命名规范
- 实现简单的状态管理机制
- 使用URL参数和localStorage管理状态
- 封装Supabase操作，提高代码复用性
- 完善的错误处理和用户反馈
- 聊天系统模块化设计，分步实现核心功能
